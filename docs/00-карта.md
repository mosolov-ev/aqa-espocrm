# Карта: с чего начать

Это обучение по проекту автотестов `aqa-espocrm`. Оно объясняет, как всё устроено и как этим пользоваться без посторонней помощи.

Читать по порядку необязательно — ниже написано, когда открывать какой документ.

---

## Если ты открыл проект впервые

Пройди по порядку, это займёт около часа:

1. **[Стенд](01-стенд.md)** — запусти приложение, против которого работают тесты. Без него тесты не пройдут.
2. **[Запуск в IntelliJ](03-запуск-в-intellij.md)** — открой проект и прогони тесты. Убедись, что всё зелёное.
3. **[Разбор кода](02-разбор-кода.md)** — пойми, как устроены тесты, слой за слоем.
4. **[Упражнения](06-упражнения.md)** — напиши первый тест сам.

## Главная мысль всего проекта

Автотест — это не «скрипт, который кликает». Это **независимая проверка утверждения о системе**.

Отсюда три правила, которые проходят через весь код:

1. **Проверяй в источнике, отличном от того, где делал действие.** Создал через интерфейс — убедись через API или в базе. Интерфейс мог нарисовать запись, не сохранив её.
2. **Убирай за собой.** Тест, оставляющий мусор, через сто прогонов начнёт ронять соседей.
3. **Не вписывай в тест то, что можно спросить у системы.** Количество записей, идентификаторы, даты — всё это меняется, и жёстко вписанные значения превращают тесты в источник ложных тревог.
